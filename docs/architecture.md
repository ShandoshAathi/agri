# AgriSense AI Architecture & System Specs

## Component Breakdown

1. **Frontend**: React + Vite + Tailwind CSS v4 + Lucide React + Recharts
2. **Backend**: FastAPI REST & WebSockets
3. **Database**: Supabase PostgreSQL
4. **AI Models**: Scikit-Learn (Crop Recommendation) & TensorFlow/OpenCV (Disease Diagnosis)
5. **IoT**: ESP32 Microcontrollers over MQTT Protocol
